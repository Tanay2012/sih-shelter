Architecture & Stack

Full-Stack Technical Specifications

Robust engineering architecture leveraging modern web and data physics technologies.

Node.js & Express API Server

Asynchronous Express backend managing user sessions via connect-mongo and handling JSON payload orchestration for calculation jobs.

Python Physics Calculation Engine

Sub-process physics calculator (simulator.py) executing thermal equilibrium and heat conduction differential equations.

MongoDB Atlas & Mongoose ORM

Cloud MongoDB database providing persistence for user accounts (with bcrypt password hashing) and historical simulation runs.

Plotly.js & Chart.js Visualizations

High-definition client-side interactive rendering for 3D thermal mesh surfaces, diurnal graphs, and material cost distributions.
